# Pong на ассемблере

Консольный пинг-понг для Linux x86-64, написанный на чистом NASM — без libc, только системные вызовы.

## Возможности

- Игра вдвоём или против компьютера
- Три скорости: медленно, нормально, быстро
- Игра до заданного числа очков (от 1 до 99)
- Угол отскока зависит от того, какой частью ракетки отбит мяч
- Плавное управление в терминалах с [протоколом клавиатуры kitty](https://sw.kovidgoyal.net/kitty/keyboard-protocol/) (kitty, foot, WezTerm, Ghostty и др.): ракетка едет, пока клавиша зажата. В остальных терминалах работает обычный ввод
- Управление работает и в русской раскладке

## Сборка

Нужны `nasm` и `ld` (binutils).

```sh
nasm -f elf64 main.asm -o pong.o
ld pong.o -o pong
```

## Запуск

```sh
./pong
```

Терминал должен быть не меньше 80×24 и поддерживать UTF-8.

## Управление

**Меню**

| Клавиша          | Действие          |
|------------------|-------------------|
| W / S, ↑ / ↓     | выбор пункта      |
| A / D, ← / →     | изменить значение |
| Enter / пробел   | старт             |
| Q                | выход             |

**Игра**

| Клавиша  | Действие                |
|----------|-------------------------|
| W / S    | левая ракетка           |
| ↑ / ↓    | правая ракетка          |
| Q, Ctrl+C| выход                   |

После победы: Enter — вернуться в меню, Q — выйти.
